# Roadmap

| Stage | Goal | Done when |
|---|---|---|
| 0 | Protocol and repo skeleton | Message schemas and test vectors exist |
| 1 | Events MVP | Claude Code + one more agent; QR pairing; relay; sessions list; approve/deny; push |
| 2 | Phone polish | Diff review, voice instructions, queued/scheduled tasks, multi-machine inbox |
| 3 | More agents | Codex, Gemini CLI, OpenCode adapters |
| 4 | Peek | Window/region streaming over WebRTC |
| 5 | Cloud runner | Sandboxed tasks that run when the PC is off |

Rule: do not start a stage before the previous one is used by real people.
